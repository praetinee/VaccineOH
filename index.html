ตั้งค่าการเชื่อมต่อ Google Sheets สด

วิธีทำ Publish to Web บน Google Sheets:

  1. เปิด Google Sheet ของคุณ
  2. ไปที่เมนู File (ไฟล์) > Share (แชร์) > Publish to web (เผยแพร่ไปยังเว็บ)
  3. เลือกชีต "ประวัติการรับวัคซีน จนท." และเปลี่ยนรูปแบบเป็น Comma-separated values (.csv)
  4. คลิกปุ่ม "Publish" แล้วคัดลอกลิงก์มาวางในช่องด้านล่าง

* ระบบจะบันทึกลิงก์นี้ไว้ในเบราว์เซอร์อัตโนมัติ (LocalStorage)
